นโยบายความเป็นส่วนตัว Privacy Policy

ปรับปรุงล่าสุด / Last updated: 26 November 2026

แอปนี้ทำอะไร / What the app does

แอป yoklaowma เป็นเครื่องมือภายในของเจ้าของช่อง "ยกเล่ามา" ใช้อัปโหลดวิดีโอที่ช่องสร้างเองไปยังช่อง YouTube ของเจ้าของช่อง และสำรองวิดีโอเหล่านั้นไว้ใน Google Drive ของเจ้าของช่อง

The yoklaowma app is an internal tool of the owner of the "Yok Lao Ma" channel. It uploads videos the channel produces to the owner's own YouTube channel and backs those videos up to the owner's own Google Drive.

ข้อมูลจาก Google ที่แอปใช้ / Google user data the app uses

  • youtube.upload: อัปโหลดวิดีโอไปยังช่อง YouTube ของเจ้าของช่องเท่านั้น to upload videos to the owner's YouTube channel only.
  • drive.file: สร้างและจัดการเฉพาะไฟล์ที่แอปนี้อัปโหลดเองใน Google Drive ของเจ้าของช่อง แอปมองไม่เห็นไฟล์อื่นใน Drive to create and manage only the files this app uploads to the owner's Google Drive; it cannot see any other file.

แอปไม่อ่าน ไม่เก็บ และไม่ประมวลผลข้อมูลส่วนบุคคลของผู้ชมหรือบุคคลอื่น ไม่ใช้ข้อมูลเพื่อโฆษณา และไม่ขาย ไม่ให้เช่า หรือไม่เปิดเผยข้อมูลแก่บุคคลที่สาม

The app does not read, store or process personal data of viewers or anyone else, does not use data for advertising, and does not sell, rent or disclose any data to third parties.

การจัดเก็บ / Storage

สิทธิ์การเข้าถึง (OAuth token) เก็บไว้บนเซิร์ฟเวอร์ส่วนตัวของเจ้าของช่อง จำกัดสิทธิ์อ่านไฟล์ไว้ที่บัญชีของระบบเท่านั้น และใช้เพื่ออัปโหลดตามที่อธิบายข้างต้นเท่านั้น

OAuth tokens are kept on the owner's private server with file access restricted to the service account, and are used only for the uploads described above.

การยกเลิกสิทธิ์ / Revoking access

ยกเลิกสิทธิ์ของแอปได้ทุกเมื่อที่ myaccount.google.com/permissions

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
